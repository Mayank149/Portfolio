AI Career Copilot

Built an agentic RAG career assistant and ATS scorer with LangGraph tool orchestration and human-in-the-loop resume editing, using a state machine that interrupts execution for interactive diff review before applying any change. Designed a dual-provider LLM architecture (Groq cloud, Ollama local) with a ChromaDB semantic retrieval layer over sentence-transformer embeddings, achieving 90% Recall@4 and 0.83 MRR@4 on a 15-query benchmark, with Groq delivering 0.81s P50 latency. Fully containerized with Docker and powered by FastAPI.

Python FastAPI LangChain LangGraph RAG ChromaDB Groq Ollama Docker
GitHub

Technical Debug Assistant

Developed a production-style Multi-Hop Retrieval-Augmented Generation (RAG) Technical Debug Assistant that provides context-grounded solutions for technical issues using semantic search and large language models. Built the complete RAG pipeline from scratch, including document ingestion, metadata-aware chunking, semantic embedding generation, FAISS vector indexing, multi-document retrieval, context assembly, prompt engineering, and grounded response generation using Llama 3.3 70B via Groq. The application also supports live knowledge base updates through document uploads, source attribution, and retrieval score visualization for improved transparency.

Retrieval-Augmented Generation (RAG) Python FAISS Groq API Llama 3.3 70B Semantic Search Prompt Engineering
GitHub
